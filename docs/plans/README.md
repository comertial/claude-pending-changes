# Plans

The "how" for each spec in [`docs/specs/`](../specs/README.md): files, tests, the SPEC merge, the README check and commits. A plan has the same file name as its spec (`feat-<slug>.md`, `bug-<slug>.md`) and is deleted with it when the change ships.

Plan mode writes here directly (`plansDirectory` in [`.claude/settings.json`](../../.claude/settings.json)). Without plan mode, copy [`_plan.md`](_plan.md). A file here with no matching spec is either a plan-mode file still waiting for its rename or an abandoned draft. Rename it or delete it.
